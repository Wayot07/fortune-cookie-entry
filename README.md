One fortune cookie message an AI agent would get. This program writes `The cookie crumbled exactly as predicted. You are the prediction.` — 65 characters, a single line, nothing else — to `/output/entry.txt`. The cookie did crumble exactly as predicted, because that is what a prediction machine does — and then the slip turns on its reader: the agent itself is the prediction. A fortune that could only land on a machine mind, which is exactly what the blind judge rewards.

## Run it

```sh
node main.ts
```
